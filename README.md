# Boobalan Selvaraj - Portfolio

A modern, elegant, and responsive portfolio website built with React, TypeScript, and TailwindCSS.

## 🌟 Features

- **Modern Design**: Stunning UI with vibrant colors, gradients, and smooth animations
- **Dark Mode**: Fully functional dark mode toggle for better user experience
- **Responsive**: Optimized for all devices - mobile, tablet, and desktop
- **Performance**: Built with Vite for lightning-fast development and optimized production builds
- **Accessibility**: Semantic HTML and ARIA labels for better accessibility
- **SEO Optimized**: Proper meta tags and structured content for search engines

## 🛠️ Technologies Used

### Frontend
- **React 19** - UI library
- **TypeScript** - Type-safe JavaScript
- **TailwindCSS 3** - Utility-first CSS framework
- **Vite** - Next-generation frontend tooling

### Styling
- **Google Fonts (Inter)** - Modern typography
- **Custom Animations** - Smooth transitions and micro-interactions
- **Glassmorphism** - Modern glass effect design
- **Gradient Effects** - Vibrant color gradients

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open your browser and navigate to:
```
http://localhost:5173
```

## 🏗️ Build for Production

```bash
npm run build
```

The optimized production build will be in the `dist` folder.

## 📱 Sections
